# Texcelのヘルプ

TexcelはMarkdownの表を表計算のように編集するアプリです。CSV・TSVも編集でき、XLSX・ODS・HTMLはMarkdownの表として取り込みます。

以下のCtrlは、macOSではCmdに読み替えてください（「Control」と書いたものを除く）。

## 画面

| 場所 | 内容 |
| --- | --- |
| 名前ボックス | 選択中のセルの番地です。`C12`や`A1:D20`を入力してEnterを押すと、そこを選びます |
| 数式バーの左のボタン | 入力の取り消し、入力の確定、関数の挿入（fx）です |
| 数式バー | 選択中のセルの原文（数式やMarkdownの記号を含む）です。クリックするとそこから編集できます |
| 「ライブ編集」／「ソース編集」 | 数式バーの右隣で現在の表示モードを示し、押すと切り替えます |
| 表タブ・「一覧」 | 文書の中の表を切り替えます。「＋」で表を追加します |
| 倍率 | シートの表示倍率です。クリックすると倍率を選べます |
| 状態欄 | 処理の完了、注意、選択したセルの個数と行数・列数を表示します |

**ライブ編集**は数式の計算結果とMarkdownの書式の見た目を、**ソース編集**は全セルの原文を表示します。Ctrl＋/でも切り替えられ、文書の内容は変わりません。

## セルの選択と移動

- クリックか矢印キーでセルを選びます。Shift＋矢印、ドラッグ、Shift＋クリックで範囲を選び、Ctrl＋クリックで離れた範囲を追加します。
- 列見出し・行番号をクリックすると列全体・行全体を選びます。見出しをドラッグするかShift＋クリックすると連続した複数の列・行を、Ctrl＋クリックすると離れた列・行を選べます。
- 左上の角をクリックするか、Ctrl＋Aですべてのセルを選びます。
- Ctrl＋矢印で値が続く範囲の端へ、Ctrl＋Home／Endで表の先頭・使用範囲の末尾へ移動します。

## 入力と編集

- セルを選んで文字を打つと、内容を置き換えて入力を始めます。日本語入力もそのまま始められます。
- 今の内容を直すときは、F2を押すかダブルクリックします。
- Enterで確定して下へ、Tabで確定して右へ移動します。Escで入力を取り消します。
- Alt＋Enterでセル内で改行します。Markdown文書では`<br>`が入ります。
- Delete／Backspaceで選択したセルの内容を消します。

## 数式

`=`で始まる内容は数式です（例：`=B2*C2`、`=SUM(D2:D3)`）。

- 入力中にセルをクリック・ドラッグすると、その番地が数式に入ります。
- F4（macOSはCmd＋T）で参照を相対・絶対・行固定・列固定と切り替えます。
- 「fx」を押すと関数の一覧が開きます。名前の一部で絞り込めます。
- `=`で始まる文字列を値として入れたいときは、先頭に`'`を付けます。
- `00123`のような先頭ゼロ付きの文字列は数値に変えません。集計関数では無視されます。

四則演算（`+ - * / ^ %`）、比較、文字列結合（`&`）を使えます。計算する関数の一覧と説明は、末尾の「付録：使える関数」にあります。

## フィル

選択範囲の右下の小さな四角をドラッグすると、その範囲を埋めます。等間隔の数値・日付・末尾の番号は続きを作り、それ以外はコピーします。Ctrl＋D／Rで上／左のセルをコピーします。

## 行・列・表

- 行・列の挿入は「挿入」メニュー（Ctrl＋Shift＋R／C）、削除・複製・移動は「表」メニューの「行」「列」から行います。見出しやセルの右クリックメニューからも使えます。
- 表の追加・複製・削除は「表」メニューか表タブの右クリックメニューから行います。
- 列見出しの境界をドラッグすると列幅を変えられ、ダブルクリックで内容に合わせます。「表示」→「列の幅…」では半角文字数で指定します。

## Markdownの書式

| 書式 | 操作 |
| --- | --- |
| 太字・斜体 | Ctrl＋B・Ctrl＋I |
| 打ち消し | Ctrl＋Shift＋X |
| インラインコード | Ctrl＋E |
| リンク | 「書式」→「リンク」 |
| 列の左・中央・右寄せ | 「書式」→「配置」 |

書式は選択したすべての範囲にまとめて付け外しできます。リンクはCtrl＋クリックで開きます。

## 元に戻す・やり直す

Ctrl＋Zで元に戻し、Ctrl＋Shift＋Zでやり直します（WindowsはCtrl＋Yも可）。履歴は文書ごとで、保存しても消えません。

## 開く・保存する

- 「開く…」（Ctrl＋O）、ウィンドウへのドロップ、最近使ったファイルから開きます。XLSX・ODS・HTMLはMarkdownの表として取り込み、元のファイルは変えません。
- 「保存」（Ctrl＋S）は開いたファイルへ上書きします。「名前を付けて保存…」（Ctrl＋Shift＋S）では、形式（Markdown・CSV・TSV）と、数式を残すか計算結果の値にするかを選びます。
- CSV・TSVには選んだ1つの表だけを書きます。失われる内容があれば保存の前に表示します。

## コピーと貼り付け

- Ctrl＋C／X／Vでコピー・切り取り・貼り付けします。ExcelやGoogle スプレッドシートとの間でもやり取りできます。
- Ctrl＋Shift＋Vはテキストとして貼り付けます。
- 「編集」→「形式を選択してコピー…」「形式を選択して貼り付け…」（Ctrl＋Alt＋V、macOSはCmd＋Control＋V）で、形式や内容を選べます。

## 表示

- Ctrl＋＋／−でシートの表示倍率を変え、Ctrl＋0で100%に戻します。
- 「表示」メニューで、テキストの折り返し、ウィンドウ枠の固定、列の幅の自動調整を選べます。
- 「設定…」で言語、テーマ、フォント、UIの文字サイズ、空白等の表示を変えられます。

## 検索とデータの整理

- 「編集」→「検索…」（Ctrl＋F）、「置換…」（Ctrl＋H、macOSはCmd＋Shift＋H）で検索・置換します。
- 「データ」メニューで、並べ替え、前後の空白の除去、列の分割・結合、転置、重複行の検出・削除を行います。まとめた変更は1回の「元に戻す」で取り消せます。

## 付録：使える関数

数式で計算する関数は次のとおりです。「fx」の一覧にはこのほかの関数名も並びますが、計算するのはこの表の関数だけです。それ以外の関数を含む数式は、入力した式をそのまま保ちます。`[ ]`で囲んだ引数は省略できます。

| 分類 | 書式 | 説明 |
| --- | --- | --- |
| 集計 | `SUM(値1, …)` | 数値の合計を返します。範囲内の文字列は無視します |
| 集計 | `AVERAGE(値1, …)` | 数値の平均を返します |
| 集計 | `MIN(値1, …)` | 数値の最小値を返します |
| 集計 | `MAX(値1, …)` | 数値の最大値を返します |
| 集計 | `COUNT(値1, …)` | 数値が入ったセルの数を返します |
| 集計 | `COUNTA(値1, …)` | 空でないセルの数を返します |
| 集計 | `COUNTIF(範囲, 条件)` | 条件に合うセルの数を返します（例：`">=10"`） |
| 集計 | `SUMIF(範囲, 条件, [合計範囲])` | 条件に合う行の値を合計します |
| 条件 | `IF(条件, 真の場合, [偽の場合])` | 条件に応じて2つの値のどちらかを返します |
| 条件 | `IFERROR(値, エラーの場合)` | 値がエラーなら代わりの値を返します |
| 条件 | `AND(条件1, …)` | すべての条件が真のとき真を返します |
| 条件 | `OR(条件1, …)` | いずれかの条件が真のとき真を返します |
| 条件 | `NOT(条件)` | 真と偽を反転します |
| 数値 | `ABS(数値)` | 絶対値を返します |
| 数値 | `ROUND(数値, 桁数)` | 指定した桁で四捨五入します |
| 数値 | `ROUNDUP(数値, 桁数)` | 指定した桁で切り上げます（0から遠い方へ） |
| 数値 | `ROUNDDOWN(数値, 桁数)` | 指定した桁で切り捨てます（0に近い方へ） |
| 文字列 | `LEN(文字列)` | 文字数を返します |
| 文字列 | `LEFT(文字列, [文字数])` | 先頭から指定した文字数を取り出します |
| 文字列 | `RIGHT(文字列, [文字数])` | 末尾から指定した文字数を取り出します |
| 文字列 | `MID(文字列, 開始位置, 文字数)` | 途中の位置から指定した文字数を取り出します |
| 文字列 | `TRIM(文字列)` | 前後の空白を除き、間の連続する空白を1つにします |
| 文字列 | `CONCATENATE(文字列1, …)` | 文字列をつなげます。`&`と同じです |
| 文字列 | `VALUE(文字列)` | 数値を表す文字列を数値に変えます |
| 日付 | `DATE(年, 月, 日)` | 年・月・日から日付を作ります |
| 日付 | `YEAR(日付)` | 日付の年を返します |
| 日付 | `MONTH(日付)` | 日付の月（1〜12）を返します |
| 日付 | `DAY(日付)` | 日付の日（1〜31）を返します |
