# 確認用サンプル

個人データを含まない小さな固定入力と、それを開いたときの期待結果。期待結果は仕様から導いたもので、入力があることを動作確認の証拠にしない。自動テストで確かめている範囲と未確認の範囲は[詳細設計書](../docs/detail-spec.md)の12節を参照。

| ファイル | 確認すること |
| --- | --- |
| `tables.md` | 2つの表、修飾、日英混在、原文表示、周辺文章の保持 |
| `column-alignment.md` | 左・中央・右・指定なしの列配置。区切り行のハイフン数と左右の余白は列ごとに異なる |
| `strings.csv` | 文字列の保持、引用符、セル内改行、不揃いな行、空行 |
| `bom-tables.md` | UTF-8 BOMとCRLFで始まる3表。日本語表示の表名は順に「表1」「追加注文」「表3」。1表目のB2を12から13に直して保存し、BOM、改行、表の間の文章が保たれること |
| `cp932-inventory.csv` | BOMなしのCP932、CRLF。読み込み確認画面で「鉛筆」「用紙」が読めること。開いてA2の「鉛筆」を「鉛筆改」に変更して保存すると、元ファイルとの差はCP932の「改」の2バイトだけになる。行末のCRLFと最後の改行も保持する |
| `cell-display.md` | 左・中央・右寄せで先頭ゼロ・20桁文字列・インラインコード・式を表示 |
| `cell-display-overflow.md` | 折返しを使わない長い複数行の左・中央・右寄せを確認 |
| `formulas.csv` | 数式評価と参照更新。ヘッダーなしで開く |
| `workbook.xlsx` | 複数シート、型、式と保存結果、書式、非対応要素の報告 |
| `workbook.ods` | ODSの複数シート、型、OpenFormulaの書き換え、修飾・リンク、結合・非表示・コメントの報告 |
| `formatting-only.xlsx` | 値・表構造を保った書式のみの欠落と非モーダル通知 |
| `rules.xlsx` | AutoFilter、whole数値・参照一覧の入力規則、値比較の条件付き書式 |
| `io-roundtrip.csv` / `io-roundtrip.md` / `io-roundtrip.html` / `io-roundtrip.xlsx` | 2×2の共通値で4入力形式からMD/CSVへの8経路を確認 |
| `html-source.html` | 離れた場所の2表の取り込み、Markdown修飾・リンクへの変換、表外内容の省略通知 |
| `html-nested-readonly.html` | 入れ子表を診断し、離れた通常表をMarkdownへ取り込む |
| `html-rich-japanese.html` | 日本語の太字・斜体・全セルリンク、生成表名、CSS非描画を画面で確認 |

CSV・Markdownの入力上限は64 MiB、500,000セル、1,048,576行、16,384列。超過時は読み込みを中止し、部分的な文書を開かない。EOFでの列・行同時追記、単一空フィールド、GFMの不足セル、外側pipeを省いた行、末尾バックスラッシュは実装回帰で個別に確認する。

## Markdown・CSVの期待結果

- `tables.md` の表タブは「商品」「注記」。コードブロック内の表は対象外。
- `column-alignment.md` のC2を12から13にして保存すると、そのセルの末尾の1バイトだけが `2` から `3` に変わる。B列を左寄せにすると区切り行の `|:---:|` が `|:---|` になり、他の列の記号・余白は残る。それぞれ元の入力から試す。
- 同じ表で空のE列を右寄せにして保存しても、ファイルのバイト列は変わらない。続けてE2に値を入力して保存すると5列になり、E列の区切り末尾にコロンが付く。列の移動で配置はその列に追従し、新たに挿入した列の配置は指定なしとなる。
- 数式評価は既定で有効。商品表のD2=3600、D3=1600、D4=5200。
- 注記の `A\|B` は閲覧時に `A|B`、`<br>` は改行。修飾セルは編集時に元の記法を操作する。
- 未編集保存では元バイト列を保持し、セル変更で前後の文章やコードブロックを変えない。
- `strings.csv` はUTF-8・BOMなし・LF。5つのデータレコード相当（ヘッダーを除く通常4行と末尾の空レコード）を含む。物理行数でレコードを分割しない。
- `00123`、20桁の識別子、日付らしい文字列を保持する。`=SUM(A1:A2)` は数式として評価する。式に見える文字列を入力・保存する場合は先頭にアポストロフィを付ける。
- `cell-display.md` の `00123` と20桁識別子はどの列配置でも文字列値を保持する。列幅を超える表示は省略記号で知らせ、保存値を短くしない。数式結果は数値として右寄せにし、Markdownの明示配置は優先する。
- `cell-display-overflow.md` は長い1行目を省略記号で示し、2行目の `x` を保つ。折返しは有効にしない。
- `=SUM(A1:A2)` は0を返す。A1の `id` とA2の `00123` はどちらも数値の正規表記ではない文字列で、Excelと同じく集計関数は文字列を無視する。
- 末尾の `literal` を持つレコードは2フィールド、通常レコードは3フィールド。空レコードも保持する。

## 数式の期待結果

`formulas.csv` は既定で数式を評価する。A9の先頭ゼロを持つ文字列 `00123` を保持する。

| セル | 期待する結果 |
| --- | --- |
| C1 / C2 / C3 | 3600 / 1600 / 5200 |
| C4 | 文字列 `OK` |
| C5 | ゼロ除算エラー |
| C6 | 文字列 `error` |
| C7 | 循環参照。最新の数値として使わない |
| C8 | 未対応式。式を保存し、仮の0を表示しない |
| C9 | 5 |
| C10 | 3600 |

独立した操作例：C10をC11へコピーすると式は `=$A$1*B2`、値は2400。元ファイルを開き直し先頭に1行挿入すると元C1の式はC2の `=A2*B2` となり3600。これらは期待値であり実測値ではない。

## XLSX入力の情報と取り込みの期待結果

`workbook.xlsx` は `python3 samples/generate_xlsx.py` で再生成できる合成OOXML。A3の空文字は `<t/>` で記述する。キャッシュ値は下記の既知の期待値を記録したもので、Excelや計算エンジンが評価した証拠ではない。XMLを明示することで空文字・空セルや式の結果を作者側エンジンの自動変換から独立させている。互換プローブはA3を `<t></t>` にした一時fixtureも読んで、両形式が同じ空文字になることを確認する。

| シート・範囲 | 期待する情報 |
| --- | --- |
| 売上!C2:C4 | 式と保存結果3600・1600・5200を別々に取得 |
| 売上!A1:C1 | 白い太字・青背景、先頭行固定、列幅指定 |
| 型と書式!A1 / B1 | 文字列 `00123` / 数値123 |
| 型と書式!A2 / B2 | 20桁の文字列 / 真偽値TRUE |
| 型と書式!A3 / B3 | 明示的な空文字 / 空セル |
| 型と書式!A4 / B4 | 「重要」だけ太字 / 日付値45292（1900基準、2024-01-01） |
| 型と書式!A5 / B5 | セル内改行と折り返し / 式 `=1/0` と保存エラー |
| 型と書式!A6 | `=SUM(A1:A2)` という文字列。数式にしない |
| 型と書式!A7:B7 / 8行 / C列 | 結合 / 非表示行 / 非表示列 |
| 売上の印刷設定 | 非対応として読み込みレポートへ。元ファイルは変更しない |

上の表は入力に含まれる情報である。アプリは各シートをMarkdown表へ取り込み、Markdownで表せる修飾・リンク・改行・列配置を引き継ぐ。色・罫線・数値書式・非表示・入力規則・条件付き書式などの省略を報告する。結合は左上の値を残して平坦化する。取り込み元XLSXへ保存しない。

`rules.xlsx` はルールを含む入力で、AutoFilter A1:C5、整数1〜10、`Lookup!A1:A3` の一覧、B2:B5のbetween条件と単色背景を持つ。Markdownへ取り込むとこれらはすべて失われ、レポートにはフィルター1件（A1:C5）、入力規則2件、条件付き書式1件以上が「保持できません」として載る。

`workbook.ods` は `python3 samples/generate_ods.py` で再生成できる合成ODS。LibreOfficeが書く形（シート端まで繰り返す空行・空列、名前付きスタイル、`text:s`など）にならって手で書いたXMLで、LibreOfficeが書き出したファイルではない。キャッシュ値は既知の期待値を記録したもの。

| シート・範囲 | 期待する情報 |
| --- | --- |
| 売上!A1:D1 | 名前付きスタイル経由の太字。取り込み後は見出し行 |
| 売上!D2:D4 | `of:=[.B2]*[.C2]` などを `=B2*C2`・`=SUM(D2:D3)` として取り込む。保存結果は3600・1600・5200 |
| 売上!D列 | 非表示列。表示設定の損失として報告 |
| 売上 | 末尾の空行1,048,572行を展開せず、表は4行 |
| 型と書式!A1 / B1 | 文字列 `00123` / 真偽値TRUE |
| 型と書式!A2 / B2 | 日付値45292（2024-01-01） / 数値0.25。どちらも表示形式の損失を報告 |
| 型と書式!A3 / B3 | 「重要」だけ斜体 / `https://example.com/` へのリンク |
| 型と書式!A4 / B4 | 2段落を1セルのセル内改行に / `text:s` による2つの空白 |
| 型と書式!A5:B5 | 結合。左上の値を残す |
| 型と書式!A6 / B6 | 別シート参照 `[$売上.D4]` は保存値5200へ置き換えて報告 / 文字列内の `;` を保った `=IF(A1="a;b",1,2)` |
| 型と書式!7行 | 非表示行、背景色、コメント（`office:annotation`）。コメントは取り込まず要素名を報告 |

`formatting-only.xlsx` は `python3 samples/generate_formatting_only_xlsx.py` で再生成できる最小OOXML入力。A1のフォントサイズだけがMarkdownへ移らず、値と表構造はそのまま残る。読み込み時は状態欄に通知と［詳細］を表示し、［詳細］から開くレポートに拡張子付きファイル名とOS地域の日時を示す。対照として `workbook.xlsx` の結合範囲A7:B7は内容・表構造への影響として自動レポートを開く。

## 形式変換の期待結果

4つの `io-roundtrip` 入力は `項目 / 値` と `りんご / 古い` の2×2表を持つ。4入力形式からMarkdown/CSVへの8経路で、B2を `新しい値` に編集して保存し、再読込後もB2が `新しい値` であることを確認する。XLSX/HTMLは先にMarkdown文書へ取り込み、元ファイルを変更しない。XLSX入力は `python3 samples/generate_io_roundtrip_xlsx.py` で再生成できる。

この8経路は基本的な値の保持を確認する。複数表からCSVへ出力するときは対象表を選び、部分出力だけで元文書を保存済みにしない。修飾・数式・Undo・保存失敗は専用の回帰で確認する。旧16経路の結果を現行仕様の完了証拠に流用しない。

この入力ではHTML/XLSXの取り込み時に表名の見出しが付くため、CSVへの2経路は見出しを省略する部分出力となり、元文書の未保存状態を維持する。他の6経路は保存先を採用して保存済みとなる。`production_io_routes_edit_b2_and_keep_import_sources_untouched`は通常の読込worker・セル編集確定・保存・再読込を接続してこの違いを確認する。OSのファイル選択や実キーボード操作の確認ではない。

`html-source.html` は在庫表と注記表を持つ。表をMarkdownへ取り込み、表外文章・コメント・CSS・scriptは取り込まず、その扱いをレポートに示す。CSSとscriptを実行・取得しない。`html-nested-readonly.html` は旧仕様の名前を持つ入力であり、現行仕様では入れ子構造を診断し、2つ目の独立表を取り込む。HTML原文を編集可能な文書として開かない。

`html-rich-japanese.html` を日本語UIで開くと、captionのない表タブは「表1」となる。B2は「手仕事の模様」で「手仕事」だけ太字、C2は「詳細を見る」の外部リンク、B3は斜体の「軽くて丈夫」。CSSの黄色背景は取り込まない。これは表示期待値であり、OS操作の確認結果ではない。

HTML入力はUTF-8とUTF-8 BOMを受け入れる。他のcharsetを実際の `meta` 要素が宣言する場合はASCII本文でも読み込みを拒否する。太字・斜体・取り消し線・インラインコード・リンク・改行をMarkdownへ変換する。部分リンクや複数リンクもMarkdownで表現できる範囲で引き継ぐ。表現できない構造は診断し、黙って消さない。

## 操作感の確認

上記の小さな表で選択、F2、Enter／Esc、日本語変換確定、編集バー、表タブ、Undo／Redoを確認する。Noto設定とライト／ダークで読みやすさを確認する。実画面の確認をしていないOSは未確認と記録する。

## 連続操作用の入力

`interaction-workflow.md`は、実機確認と操作シナリオで共通に使う3表の小さな入力例。コピーして使用し、検証済みの証拠には数えない。

- `Input`のA2は`abc`。セル内・数式バーで日本語変換し、取消・見出しや表タブへの移動後も確定済みの文字と入力先が一致することを確認する。
- `Input`のC2/C3は文字列の識別子。先頭ゼロと20桁の文字列を保存・再読込で保持し、狭い列でも切れていることが分かる表示になることを確認する。
- `Sales`のD2/D3の期待値はともに240。同じ表の数式として計算する。
- `Notes`は太字・コード・リンクの表示とソース編集用。3表を切り替え、アクティブな表を見分けられることを確認する。
- 表の外の2つの英文は、セル編集と保存後も維持する。3文書の確認にはこの入力を別名で3つコピーして使う。
