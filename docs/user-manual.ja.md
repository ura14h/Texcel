# Texcel 取扱説明書

対象バージョン: 0.2.1

この説明書は、配布パッケージからTexcelを起動し、表を編集して保存するまでの操作をまとめたものです。[English version](user-manual.en.md)

## 1. Texcelでできること

TexcelはMarkdownの表を表計算ソフトのように編集するアプリです。セルの値と数式の計算結果、太字やリンクなどのMarkdownの書式を同じ表で確かめながら編集できます。

| ファイル | 開く | 保存 |
| --- | --- | --- |
| Markdown（.md、.markdown） | 文書内のすべての表を編集 | 表の外の文章や手を付けていない部分を残して保存 |
| CSV・TSV（.csv、.tsv） | 1つの表として編集 | 元の区切り文字・文字コード・改行のまま保存 |
| XLSX（.xlsx） | 各シートをMarkdownの表として取り込む | XLSXには保存しない |
| HTML（.html、.htm） | 各表をMarkdownの表として取り込む | HTMLには保存しない |

ファイルはパソコンの中だけで扱います。アカウントやネットワーク接続は必要ありません。

## 2. 動作環境

- macOS、Windows、Linuxで動きます。
- 画面の描画にGPUを使います。GPUのドライバーが使えない環境では、起動時にエラーが表示されて起動しません。
- Linuxでは、ファイルを選ぶダイアログにXDGデスクトップポータル（`xdg-desktop-portal-gtk`や`xdg-desktop-portal-kde`など）が必要です。
- 画面の言語は英語と日本語に対応しています。最初はOSの言語に合わせて表示します。

## 3. パッケージの中身と起動

macOS版とWindows版は`Texcel-mac-<バージョン>.zip`、`Texcel-windows-<バージョン>.zip`というzipファイルで配布します。zipの中には、Texcel本体、`licenses`フォルダ、この取扱説明書（日本語版と英語版）が入っています。`licenses`にはTexcelと、Texcelが使っているライブラリ・フォントのライセンス文があります。

### 3.1 macOS

`Texcel-mac-<バージョン>.zip`をダブルクリックして展開します。中身は次のとおりです。

```
Texcel-mac-<バージョン>/
├── Texcel.app
├── licenses/
├── user-manual.en.md
└── user-manual.ja.md
```

1. `Texcel.app`を「アプリケーション」フォルダへコピーします。
2. `Texcel.app`をダブルクリックして起動します。

Apple Silicon（M1以降）のMacとIntel Macのどちらでも動きます。

このパッケージは配布用の公証（ノータリゼーション）を受けていません。別のMacからコピーしたりダウンロードしたりした場合、初回の起動時に「開けません」と表示されることがあります。そのときは「システム設定」→「プライバシーとセキュリティ」を開き、Texcelについての表示にある「このまま開く」を押してから、もう一度起動してください。

Finderでファイルを右クリックし、「このアプリケーションで開く」からTexcelを選ぶこともできます。

### 3.2 Windows

`Texcel-windows-<バージョン>.zip`を右クリックし、「すべて展開」で展開します。中身は次のとおりです。

```
Texcel-windows-<バージョン>\
├── Texcel.exe
├── licenses\
├── user-manual.en.md
└── user-manual.ja.md
```

1. 展開したフォルダを好きな場所（たとえば`C:\Program Files\Texcel`や自分のドキュメントの下）へ置きます。
2. `Texcel.exe`をダブルクリックして起動します。

このパッケージにはコード署名がありません。初回の起動時に「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」を押してから「実行」を押します。

ファイルをTexcelで開くには、エクスプローラーでファイルを右クリックし、「プログラムから開く」→「別のプログラムを選択」→「このPCで別のアプリを探す」で`Texcel.exe`を選びます。

### 3.3 Linux

パッケージの中身（freedesktopの配置）:

```
linux/
└── usr/
    ├── bin/texcel
    └── share/
        ├── applications/net.homeunix.hio.app.Texcel.desktop
        ├── icons/hicolor/256x256/apps/texcel.png
        └── doc/texcel/licenses/
```

自分のユーザーだけで使う場合は、`usr`の中身をホームフォルダの`~/.local`へコピーします。

```bash
cp -R linux/usr/. ~/.local/
```

すべてのユーザーで使う場合は`/usr/local`へコピーします。

```bash
sudo cp -R linux/usr/. /usr/local/
```

コピー後、アプリケーションの一覧から「Texcel」を選ぶか、端末で`texcel`と入力して起動します。`~/.local`へコピーした場合は、`~/.local/bin`がコマンドの検索パス（`PATH`）に入っている必要があります。

### 3.4 ファイルを指定して起動する

Texcelには次の方法でファイルを渡せます。どれも「開く…」と同じ読み込みになります。

- 起動中のウィンドウへファイルをドラッグ＆ドロップする
- 「ファイル」→「最近使ったファイルを開く」から選ぶ
- コマンドラインで`texcel ファイル名`のようにファイルを指定する（Windowsでは`Texcel.exe ファイル名`）
- OSの「このアプリケーションで開く」「プログラムから開く」でTexcelを選ぶ

## 4. 画面の見方

起動すると、空のシート（表1）が開きます。どのセルからでもすぐに入力できます。

| 場所 | 内容 |
| --- | --- |
| メニュー | 「ファイル」「編集」「表示」「挿入」「書式」「データ」「ヘルプ」。macOSは画面上端のメニューバーに「ウィンドウ」も加わります。Windowsはウィンドウのメニューバー（Altキーでも操作できます）、Linuxはウィンドウ内のメニューです |
| 名前ボックス | 選択中のセルの番地（例：`B2`）を表示します。`C12`や`A1:D20`を入力してEnterを押すと、そのセルや範囲を選択します。`$C$12`・`$C12`・`C$12`のような絶対・混合の書き方も使えます |
| ✗ ✓ fx | ✗は入力の取り消し、✓は入力の確定、fxは関数の挿入です。✗と✓は入力中だけ押せます |
| 数式バー | 選択中のセルの内容（数式やMarkdownの記号を含む原文）を表示します。クリックするとそこから編集できます |
| 表のグリッド | 列記号（A、B、…）と行番号（1、2、…）の付いたセルの並びです |
| 表タブ | 文書の中の表を切り替えます。「＋」で表を追加します |
| 「一覧」 | 文書の中の表を一覧から選びます。表名と、A1にいちばん近いセルの内容を表示します |
| 「ライブ編集」／「ソース編集」 | 表示モードを切り替えるボタンです。現在のモードの名前を表示しています |
| 状態欄 | 保存・置換・行の挿入などが終わったことの通知、対処が必要な失敗や注意、処理中の取り消しボタン、選択したセルの個数を表示します |

ウィンドウ1つが1つの文書です。「新しい文書」や「開く…」は新しいウィンドウを開きます。すでに開いているファイルを開こうとすると、そのウィンドウが前に出ます。未保存の変更があると、ウィンドウのタイトルに印が付きます（macOSでは閉じるボタンの中に点が付きます）。

### 4.1 ライブ編集とソース編集

- **ライブ編集**（既定）: 数式は計算結果、Markdownの書式は太字・斜体・リンクなどの見た目で表示します。
- **ソース編集**: すべてのセルにMarkdownの原文（数式や`**`などの記号）を表示します。

画面右下のボタン、「表示」メニュー、またはCtrl＋/（macOSはCmd＋/）で切り替えます。切り替えても文書の内容は変わりません。

## 5. 基本操作

以下では、macOSのCmdキーをCtrlと読み替えてください（「Ctrl/Cmd」と書いたもの）。

### 5.1 セルの選択と移動

- クリックまたは矢印キーでセルを選びます。
- Shift＋矢印、ドラッグ、Shift＋クリックで範囲を選びます。Ctrl/Cmd＋クリックで離れた範囲を追加できます。
- 列見出しや行番号をクリックすると、列全体・行全体を選びます。左上の角（行番号と列見出しが交わる空欄）をクリックすると、すべてのセルを選びます。
- Ctrl/Cmd＋矢印で、値が続いている範囲の端へ移動します。
- 名前ボックスに番地や範囲を入力すると、そこへ移動します。

### 5.2 入力と編集

- セルを選んで文字を打つと、セルの内容を置き換えて入力を始めます。日本語入力もそのまま始められます。
- 今の内容を直すときは、F2を押すかセルをダブルクリックします。数式バーをクリックして編集することもできます。
- Enterで確定して下へ、Tabで確定して右へ移動します。Shiftを押すと逆方向です。数式バーの✓で確定すると、選択は動きません。
- Escまたは数式バーの✗で、入力を取り消して元の内容に戻します。
- 数式バーで編集中に入力欄を右クリックすると、元に戻す・やり直す・切り取り・コピー・貼り付け・すべて選択を使えます。
- セル内で改行するときはAlt＋Enterを押します（保存時は`<br>`になります）。
- Delete／Backspaceで選択したセルの内容を消します。

セルを選んで直接入力を始めたときは、矢印キーで入力を確定して隣のセルへ移動します。F2やダブルクリックで編集を始めたときは、矢印キーで文字カーソルが動きます。

### 5.3 数式

`=`で始まる内容は数式として計算します（例：`=B2*C2`、`=SUM(D2:D3)`）。

- 数式の入力中にセルをクリックやドラッグすると、その番地が数式に入ります。入った参照は色付きの枠で表示されます。
- F2で、文字カーソルの移動と参照の選択を切り替えます。
- F4（macOSはCmd＋T）で、参照を相対→絶対→行固定→列固定の順に切り替えます。
- 数式バーの「fx」を押すと関数の一覧が開きます。名前の一部を入力して絞り込み、関数を選ぶと`=関数名()`が入り、括弧の間で続けて入力できます。セルをクリックやドラッグして範囲を指定することもできます。
- 「`=`」で始まる文字列をそのまま値として入れたいときは、先頭に`'`を付けます（`'=A1`は文字列「=A1」になります）。
- `00123`のような先頭ゼロ付きの文字列、20桁の識別子、日付らしい文字列は、自動で数値に変えません。SUMなどの集計では無視されます。数値として扱いたいときは`=VALUE()`を使います。

数式の計算結果を値に置き換えるには、「データ」→「選択範囲の数式を結果で置き換える」を使います。

### 5.4 フィル

選択範囲の右下にある小さな四角（フィルハンドル）をドラッグすると、ドラッグした範囲を埋めます。

- 1列または1行に2つ以上並んだ値が、等間隔の数値・日付・末尾の番号（例：`Item1`、`Item2`）であれば、その続きを作ります。
- それ以外（1セルだけ、数式、並びが読めない値）はコピーします。

「編集」→「フィル」から、コピーでのフィルと連続データでのフィルを明示的に選ぶこともできます。Ctrl＋D／Ctrl＋Rで、上／左のセルの内容をコピーします。

### 5.5 行・列・表の操作

- 行・列の挿入は「挿入」メニュー、削除・複製・移動は「編集」→「行」「列」から行います。セル・行番号・列見出しの右クリックメニューからも実行できます。挿入は、選択した行の上、選択した列の左に入ります。
- 列見出しの境界をドラッグすると列幅を変えられます。ダブルクリックで内容に合わせます。列幅はファイルに保存されない表示設定です。
- 表の追加・複製・削除は「編集」→「表」、または表タブの右クリックメニューから行います。CSV文書には表を1つしか持てません。

### 5.6 Markdownの書式

「書式」メニューやショートカットで、選んだセルに書式を付けたり外したりします。

| 書式 | ショートカット |
| --- | --- |
| 太字 | Ctrl/Cmd＋B |
| 斜体 | Ctrl/Cmd＋I |
| 打ち消し | Ctrl/Cmd＋Shift＋X |
| インラインコード | Ctrl/Cmd＋E |
| リンク | 「書式」→「リンク」→「リンクを追加・編集…」 |
| 列の左揃え・中央揃え・右揃え | 「書式」→「配置」 |

列見出しには、Markdownの区切り行と同じく配置が`:`で表示されます。左揃えは左端、中央揃えは両端、右揃えは右端に付き、配置を指定していない列には付きません。

リンクを開くときは、Ctrl/Cmdを押しながらクリックするか、「書式」→「リンク」→「リンクを開く」を使います。

### 5.7 元に戻す・やり直す

Ctrl/Cmd＋Zで元に戻し、Ctrl/Cmd＋Shift＋Zでやり直します（WindowsではCtrl＋Yも使えます）。履歴は文書ごとに1つで、保存したり表を切り替えたりしても消えません。

## 6. ファイルを開く

「ファイル」→「開く…」（Ctrl/Cmd＋O）でファイルを選びます。

### 6.1 CSV・TSV

区切り文字と文字コードがはっきり分かるファイルは、そのまま開きます。分からない場合や、UTF-8ではなくShift_JIS（CP932）のファイルは、先頭数行のプレビューと条件の画面を表示します。区切り文字・文字コード・見出し行の有無を確かめてから開いてください。開いた後に条件を変えたいときは、文書を閉じてから開き直します。

### 6.2 XLSX・HTML

XLSXの各シート、HTMLの各表を、Markdownの表として取り込みます。元のファイルは保存先にならず、変更もしません。保存するときはMarkdownかCSVを選びます。

取り込めなかった情報があると、読み込みレポートで知らせます。

- 値・数式・表の構造が失われた場合は、「XLSX読み込みレポート」「HTML読み込みレポート」のダイアログを自動で表示します。
- 色や罫線など見た目の書式だけが失われた場合は、状態欄にお知らせと「詳細」ボタンを表示します。「詳細」でレポートを開けます。

レポートは「結果」「箇所」「詳細」の3列です。左の行を選ぶと、右の「詳細」に場所・理由・対象範囲が表示されます。「レポートを保存…」でテキストファイルに保存できます。

## 7. 保存する

| 操作 | 内容 |
| --- | --- |
| 「保存」（Ctrl/Cmd＋S） | 開いたファイルへ上書きします。無題の文書や取り込んだ文書では、保存先を選ぶダイアログを表示します |
| 「名前を付けて保存…」（Ctrl/Cmd＋Shift＋S） | 形式と内容を選んでから保存先を選びます |

保存のダイアログでは次の項目を選びます。

- **形式**: MarkdownかCSV。
- **対象の表**（CSVのとき）: 保存する表を1つ選びます。
- **内容**: 「数式を残す」か「計算結果の値」。既定は「数式を残す」です。

注意:

- Markdownで「計算結果の値」を選ぶと、別ファイルへの書き出しになります。文書の保存先や未保存の印は変わりません。
- CSVには選んだ1つの表しか書けません。ほかの表やMarkdownの書式などが失われる場合は、保存の前に何が失われるかを表示します。文書全体をCSVで表せないときは、CSVファイルを書いても文書の保存先や未保存の印は変わりません。
- 手を付けていないMarkdown・CSVを保存しても、ファイルの中身は1バイトも変わりません。表の外の文章や、編集していないセルの書き方もそのまま残ります。Texcelが書いたセルは、値の前後に空白を1つずつ置きます。
- 開いた後にほかのアプリでファイルが変更されていた場合は、保存の前に「上書き」「名前を付けて保存…」「キャンセル」から選ぶ確認を表示します。

## 8. コピーと貼り付け

- Ctrl/Cmd＋C／X／Vで、セルの範囲をコピー・切り取り・貼り付けします。ExcelやGoogle スプレッドシートとの間でもやり取りできます。
- 「編集」→「形式を選択してコピー…」では、形式（TSV、CSV、Markdown表、HTML）と内容（原文か、表示どおりの値か）を選べます。
- 「編集」→「形式を選択して貼り付け…」では、「値のみ」「転置」「空白セルをスキップ」を選べます。
- 表の右端や下端を越えて貼り付けると、表が広がります。

## 9. 表示の調整

「表示」メニューから次の操作ができます。どれもファイルの内容は変えません。

- 拡大・縮小: シートの表示倍率をCtrl/Cmd＋＋／−で10%ずつ変え、Ctrl/Cmd＋0で100%に戻します。画面下部の「ライブ編集」の右にある倍率をクリックすると、200%・100%・75%・50%・25%・任意指定（10%〜400%）から選べます。表示倍率はウィンドウごとに別々で、メニューや数式バー、ダイアログの大きさは変わりません。
- テキストの折り返し: 長い内容を折り返すかどうかを選びます。
- ウィンドウ枠の固定: 選択した行や列までを固定して、スクロールしても表示したままにします。
- 列の幅…: 列幅を数値（小数2桁まで）で指定します。
- 列の幅の自動調整: 表のすべての列の幅を内容に合わせます。

## 10. 検索とデータの整理

- 「編集」→「検索…」（Ctrl/Cmd＋F）、「置換…」（Ctrl＋H、macOSはCmd＋Shift＋H）で、選択範囲・表・文書を対象に検索・置換します。原文と表示結果のどちらを検索するか選べます。置換は変更内容を確認してから適用します。
- 「データ」→「表全体を複数列で並べ替え…」で、複数の列を使って並べ替えます。
- 「データ」→「整理」で、前後の空白の除去、列の分割・結合、転置を行います。
- 「データ」→「重複」で、重複した行を検出・削除します。

まとめて行った変更は、1回の「元に戻す」で取り消せます。

## 11. 設定

「設定…」は、macOSでは「Texcel」メニュー（Cmd＋,）、Windows・Linuxでは「ファイル」メニューにあります。変更はすぐに反映され、文書の内容は変わりません。

| 項目 | 選べる内容 |
| --- | --- |
| アプリの言語 | システムに従う、English、日本語 |
| テーマ | システム、ライト、ダーク |
| フォント | 自動（表示言語に合わせる）、標準、Noto Sans JP |
| UIの文字サイズ | シート以外（メニュー、数式バー、表タブ、状態欄、ダイアログ）の文字の大きさ（ピクセル数）。既定はOSの標準に合わせます |
| 空白等を表示 | 空白・タブ・改行を記号で表示する |

## 12. 閉じる・終了する・作業の復元

- 未保存の文書を閉じるときは、「保存して閉じる」「変更を破棄」「キャンセル」から選びます。終了するときは未保存の文書を1つの一覧で表示し、「すべて保存して終了」「すべて破棄して終了」「キャンセル」から選びます。
- 変更していない無題の文書や、取り込んだだけの文書は、確認なしで閉じます。
- macOSでは最後のウィンドウを閉じてもアプリは終了しません。「Texcelを終了」（Cmd＋Q）で終了します。Windows・Linuxでは最後のウィンドウを閉じると終了します。
- 編集中の内容は定期的に退避しています。アプリが異常終了した場合は、次に起動したときに未保存の作業がそれぞれのウィンドウで開きます。不要な場合は、閉じるときに「変更を破棄」を選んでください。元のファイルへ自動で上書きすることはありません。

macOSではCtrlの代わりにCmdを使います（「Control」と書いたものを除く）。

| 操作 | キー |

| 新しい文書 | Ctrl＋N |
| 開く | Ctrl＋O |
| 保存 | Ctrl＋S |
| 名前を付けて保存 | Ctrl＋Shift＋S |
| 文書を閉じる | Ctrl＋W |

## 14. 設定と退避データの保存場所

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Application Support/Texcel/` |
| Windows | `%APPDATA%\Texcel\` |
| Linux | `$XDG_CONFIG_HOME/Texcel/`（未設定なら`~/.config/Texcel/`） |

`settings.json`が設定、`recovery`フォルダが異常終了に備えた退避データです。

## 15. アンインストール

- macOS: `Texcel.app`をゴミ箱へ入れます。
- Windows: 展開して置いたフォルダを削除します。
- Linux: コピーした`bin/texcel`、`share/applications/net.homeunix.hio.app.Texcel.desktop`、`share/icons/hicolor/256x256/apps/texcel.png`、`share/doc/texcel`を削除します。

設定も消す場合は、14節のフォルダを削除します。

## 16. 困ったとき

| 症状 | 対処 |
| --- | --- |
| macOSで「開けません」と表示される | 3.1節の手順で「このまま開く」を押します |
| Windowsで「PCが保護されました」と表示される | 「詳細情報」→「実行」を押します |
| 起動時にGPUのエラーが表示される | GPUのドライバーを更新します。リモートデスクトップや仮想マシンでは描画できない場合があります |
| Linuxでファイル選択のダイアログが開かない | XDGデスクトップポータルのサービスを入れて起動します |
| CSVの文字が化ける | 文書を閉じ、開き直して条件画面で文字コードを選びます |
| 数値が合計されない | 先頭ゼロ付きなど数値とみなさない文字列です。`=VALUE()`で数値にします |
| 操作方法が分からない | 「ヘルプ」→「Texcelのヘルプ…」を開きます |
