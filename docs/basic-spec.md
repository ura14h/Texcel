# Texcel 基本仕様書

## 1. 目的と対象

TexcelはMarkdownの表を、表計算のような操作で編集するデスクトップアプリケーションである。Markdownの表が編集文書の中心であり、CSV・TSVは読み込みと保存、HTML・XLSX・ODSはMarkdown文書への取り込みに対応する。セルの原文を保ちながら、計算結果とMarkdownの修飾を同じ表で確認できる。

Windows、macOS、Linuxを対象とする。WindowsではコンソールウィンドウなしのGUIアプリとして起動する。ローカルファイルで動作し、アカウントやネットワーク接続を必要としない。GUIはRust＋eguiを使用する。

アプリ表示名はTexcel、アプリの識別子は`net.homeunix.hio.app.Texcel`、初版のバージョンは0.1.0とする。画面の文言と利用者向けメッセージ・ログは英語と日本語に対応する。既定はOS言語に従い、設定画面から切り替えられる。言語変更で文字が見切れないようにし、文書の内容は翻訳しない。各OSの実行・配布形式にアプリアイコンを付ける。

共同編集、クラウド同期、マクロ実行、Excelの完全再現、汎用プラグイン基盤、Web・モバイル版は対象外とする。

## 2. 設計原則

- 既定のライブ編集では計算結果とMarkdownの修飾を表示し、ソース編集ではセルのMarkdown原文を表示する。両者は同じ内容を表し、切替時の適用操作を設けない。
- 表示変更だけでファイル内容を変更しない。原文、値の型、計算結果、書式を区別する。
- Markdownの表外の文章と未編集の表記を尊重し、保存時も元のバイト列を残す。
- 動作は明示した規則で決める。曖昧な推測による型変換や自動修復を行わない。
- 大きなデータでも入力やスクロールを止めない。性能と互換性は実装依存のため、未測定の保証値を掲げない。

## 3. ファイルと表

1文書はMarkdownの表の集合として編集する。Markdown文書の表外の文章は画面に表示せず、保存時にそのまま残す。独自のブック保存形式は追加しない。

| 形式 | 文書内の構成 | 保存の扱い |
| --- | --- | --- |
| Markdown | 周辺文章と複数のGFMパイプテーブル | 表を編集し、周辺文章と未編集範囲を維持して保存 |
| CSV・TSV | 1つの表 | 通常の単表編集では元の区切り・文字コード・改行と未変更のバイト列を維持 |
| HTML | 複数の表 | 各表をMarkdownの表として取り込む。HTMLへ保存しない |
| XLSX | 複数のシート | 各シートをMarkdownの表として取り込む。XLSXへ保存しない |
| ODS | 複数のシート | 各シートをMarkdownの表として取り込む。ODSへ保存しない |

HTML・XLSX・ODSを開いた場合は取り込み専用のMarkdown文書を作り、元ファイルを保存先にしない。読み込めない構造や取り込み時に失われる情報は、既存の変換レポートで示す。HTMLのスクリプトやスタイルは実行・取得しない。

新規文書は、空のシート（表1）として直ちに開く。表の大きさを作成時に決めず、保存時に値のある範囲から表を作る（5.2節）。ファイル形式は保存時に選び、Markdown・CSV・TSVだけを選択できる。保存と形式を選択してコピーのダイアログは、形式をMarkdown・CSV・TSV（コピーではHTMLを最後に加える）の順に並べ、選択肢の行は操作ボタンより詰めて並べる。XLSX・ODS・HTMLを開くときはMarkdownへの取り込みとして扱う。CSVの区切り文字・文字コードの推定結果は変更可能にする。

ファイルは「開く…」、ウィンドウへのドロップ、最近使ったファイル、コマンドライン引数、OSの「このアプリで開く」、macOSのDockやLinuxのデスクトップのドックにあるアプリアイコンへのドロップから同じ読み込み処理へ渡す。Windowsのタスクバーはアイコンへのファイルのドロップを受け付けない（ピン留めやジャンプリストの操作になる）ため対応しない。実行ファイルやショートカットへのドロップはコマンドライン引数として開く。XLSX・ODS・HTMLは入口によらず取り込みとして扱う。

1つのウィンドウは1つの文書を表示する。新規作成と開く操作は新しいウィンドウを作る。既に開いているファイル（別表記のパスを含む）を開いた場合は、新しい文書を作らず、そのウィンドウを前面に出す。起動時に自動で開く変更前の無題ウィンドウは、ファイルの読み込みが成功したときだけ、そのウィンドウで読み込んだ文書へ置き換える。読み込み失敗時や、入力を始めた後は無題ウィンドウを残す。起動後に利用者が作成した新規文書はこの置き換え対象ではない。

CSVの推定が明確なら設定ダイアログなしで開く。UTF-8でなくCP932として読めるファイルは、CP932を選んだ状態でプレビューを示し、確認してから開く。必要な場合だけ先頭数行のプレビューと選択状態付きの条件画面を示す。開いた後に文字コードや区切りを変更して読み込み直す専用の操作は設けない。読み込み直す場合は、文書を閉じてから開き直す。同じ起動中に一度閉じたCSVを開き直す場合は、推定が明確でも条件画面を表示し、前回の設定を選んだ状態から変更できるようにする。

CSVのヘッダー有無は既定で「なし」。Markdownは構文上の先頭行がヘッダー。CSVをMarkdown編集文書へ昇格するときは、現在の先頭行をMarkdownのヘッダーとして使い、新しい空行は挿入しない。ヘッダーなしCSVでは先頭行の表示上の役割が変わることを変換レポートに示す。値とA1式参照の行番号は移動しない。取り込んだXLSX・ODSの先頭行も表のヘッダーとして扱う。行番号・列記号はファイルへ書き込まない。

ファイルへの書き出しは「保存」と「名前を付けて保存」だけとし、エクスポートは設けない。「保存」（Ctrl/Cmd＋S）は既存の保存先へ書くとき数式を常に式のまま書く。無題や取り込み文書の「保存」で保存先を選ぶダイアログは名前を付けて保存と同じ内容とし、数式の出力も選べる。ただし閉じる前の保存は文書全体を保存し終える必要があるため、式のままに固定する。名前を付けて保存では、MarkdownでもCSVでも、数式を「式のまま」書くか「計算結果」で書くかを選ぶ。既定は「式のまま」とする。Markdownで「計算結果」を選んだ場合は、ファイルから式が消えて文書全体を表現できないため、CSVの部分保存と同じく別ファイルへの書き出しとして扱い、文書の保存先・未保存の印・Undo履歴を変えない。再計算の済んでいない式を含む場合、「計算結果」での書き出しは既定で止める。CSVを選んだ場合は、さらに対象の表（既定は選択中の表）を選ぶ。CSV保存は明示的に選択した1つの表だけを対象とする。複数表やMarkdown修飾などCSVへ保存されない内容がある場合、保存前に対象表と失われる内容を1回だけ示す。文書全体をCSVで表現できる場合は、通常の保存として保存先と保存済み版を更新する。表現できない場合はCSVファイルを書くが、文書の保存先・未保存の印・Undo履歴は変えず、そのことを保存前の確認に明記する。

## 4. 画面と閲覧・編集

1つのウィンドウは、メニュー、名前ボックスとセル編集バー（数式バー）、表グリッド、下部の表タブ、状態欄で構成する。文書タブとツールバーは設けない。Markdown文書全体の原文を表示・編集するパネルは設けない。

リボンとツールバーは設けない。操作はOSに応じたメニュー、右クリックメニュー、ショートカットで行う。ライブ編集／ソース編集の切替は、数式バーの右隣に分けて置いた1個のボタンで行う。数式バーと切替のバーはウィンドウの左右の端まで広げ、境界に淡い縦線を1本引く。ボタンは現在のモード（「ライブ編集」または「ソース編集」）を示し、押すともう一方へ切り替わる。幅は長い方の表示に合わせて固定する。シートの表示倍率（例：「100%」）は下部の表タブ列の右端に置く。計算・保存などの処理中だけ必要な取消操作は状態欄に置き、表の位置を動かさない。行列の挿入・削除などは右クリックメニューからも実行できる。挿入は選択した行の上、選択した列の左に入り、右クリックメニューでは行番号で「上に挿入」、列見出しで「左に挿入」、セルと「挿入」メニューで「選択行の上に挿入」「選択列の左に挿入」と示す。表の表示領域を優先する。

表示の大きさは、シート（行番号・列見出し・セル）の表示倍率と、それ以外のUIの文字サイズを分けて指定する。シートの表示倍率はウィンドウごとに持ち、保存しない。下部の倍率をクリックするとダイアログで200%・100%・75%・50%・25%・任意指定（10%〜400%、1%単位）から選べる。UIの文字サイズはアプリ共通の設定で、設定画面のフォント欄の右にあるコンボボックスでポイント数（6・8・9・10・11・12・14・16・18・20・22・24）から選び、Linuxのウィンドウ内メニュー、数式バー、表タブ列、状態欄、ダイアログが連動する。既定値はOSの標準的なUI文字サイズに合わせ、macOSは13pt（選択肢に加える）、Windowsは9pt、Linuxは11ptとする。ポイントはOSの論理単位へ換算し（macOSは1pt＝1論理ポイント、Windows・Linuxは96論理ポイント／インチ）、ディスプレイのDPIやOSの拡大率の変化はその上にOSとeguiが掛けるため、移動や設定変更に追従する。UIの文字サイズを変えてもシートの大きさは変わらず、シートの表示倍率を変えてもダイアログなどは変わらない。

メニューは「ファイル・編集・表示・挿入・書式・表・データ・ヘルプ」で構成し、macOSでは「ウィンドウ」メニュー（しまう、拡大／縮小、開いているウィンドウの一覧）を加える。macOSとWindowsはOSのネイティブメニュー、Linuxはウィンドウ内メニューを使用する。macOSではアプリ名のメニューへ「Texcelについて」「設定…」「Texcelを終了」を置き、ウィンドウ内に重複するメニューバーを描かない。macOSのウィンドウ自動タブ機能は無効にし、「タブバーを表示」を出さない。WindowsはAltによるメニュー操作を使えるようにする。設定はmacOSでCmd+,、他OSはメニューから開ける。

行・列・フィルの操作と表の追加・複製・削除は「表」メニューにまとめ、行・列・フィルは操作の種類ごとのサブメニューにする。セルの右クリックは切り取り・コピー・貼り付け・形式を選択して貼り付けから始め、その後に挿入・削除・消去などを置く。挿入メニューへ削除・移動を混在させず、並べ替えはデータメニューの直下に置く。ヘルプメニューには「Texcelのヘルプ…」と「Texcelについて」を分けて置く（macOSの「Texcelについて」はアプリ名のメニューだけに置く）。「Texcelのヘルプ…」は、アプリに内蔵した操作の説明（取扱説明書の操作部分を基に専用に書いたもの）を表示言語に合わせて開く、アプリ共通の1つのモードレスウィンドウとする。GFMの見出し・段落・修飾・リスト・表・コードを描き、ウィンドウは大きさを変えられ、内容は縦にスクロールする。表はウィンドウの幅に収め、末尾に計算できる関数の章（「使える関数」）を置く。本文の左に見出しのツリー（題名を根に各節を字下げ）を置き、押すとその見出しまで本文をスクロールし、読んでいる節を強調する。ヘルプウィンドウは文字入力を受け付けない。「Texcelについて」はアプリ名・バージョン・著作権表示のダイアログとする。

画面は表計算編集ソフトとして、文書、操作、編集対象、表の内容を見分けられる構成にする。通常のグリッド線は細く控えめにし、行列見出しと選択範囲を明確にする。文字の大きさ、余白、境界、選択色を統一し、ライト・ダークの双方で表の内容を読みやすくする。 文字の役割、余白、用語、ダイアログの配置とキー操作は[詳細設計5.3・5.4節](detail-spec.md)の共通規則に従う。

設定画面はアプリ全体の「言語・外観」を単一ページで直接表示し、1項目しかないカテゴリ欄や切替は置かない。ページ見出し、項目名、補足説明の文字と余白に明確な差を付け、項目名は左、操作欄は右へ揃える。フォント見本は補助的な領域へまとめ、狭い画面や言語切替でも操作と説明を読めるようにする。設定画面ではミニマップの幅も選べる。ダイアログ左下の「初期値に戻す」は、設定画面のすべての項目をアプリの既定値に戻し、ダイアログは開いたままにする。

起動時は空のシートを開き、表示されているどのセルからでもすぐ入力できる。下部タブで文書内の表を切り替える。選択中の表タブはExcelのシートタブと同じく、グリッドと同じ背景で下からつながる形にし、選択していないタブは枠のない平らな表示にする。背景・枠・太字・下線などの印を重ねない。ウィンドウタイトルには文書名と「Texcel」を表示し、未保存ならOSの方法で印を付ける（macOSは閉じるボタンの印）。XLSX・ODS・HTMLから取り込んだ文書名は元ファイルの拡張子を保ち、取り込み由来を示す。表名はMarkdownの表の直前の見出し、取り込み元の表名、または文書順の「表1」「表2」を使い、同名は連番で区別する。CSV文書も1つの表タブを表示する。タブが収まらない場合は横スクロールと一覧から選択できる。表一覧はタブ列の右端の「一覧」ボタンとし、タブと同じ形にしない。一覧メニューの幅は最も長い項目に合わせる。ファイルから開いたMarkdown文書（512KiB以下）では、「一覧」はメニューの代わりにミニマップの表示を切り替える。ミニマップはシート領域の右側に高さいっぱいで出し、Markdownファイル全体を、かろうじて読める小さな文字でGFMとして描いて縦にスクロールする。表はセルを描かず、表名を示す箱（数行分の高さ）で表し、押すとその表に切り替える。幅は設定画面で「大」「中」「小」から選ぶ（既定は中）。表の切り替えでは各表の選択・スクロール位置を保持し、ファイル内容を変更しない。

変更していない無題文書と、XLSX・ODS・HTMLから取り込んだだけの文書は確認なしで閉じられ、変更がない状態でアプリを終了するときも確認を出さない。保存前のセル編集や文書ソースdraftも変更として扱う。ウィンドウを閉じるときの確認には「保存して閉じる」「変更を破棄」「キャンセル」を用意する。アプリ終了時は未保存の文書を1つの一覧で示し、「すべて保存して終了」「すべて破棄して終了」「キャンセル」を用意する。新しいウィンドウは、作業中のウィンドウと同じ大きさで右下へ少しずらして開く。最後のウィンドウを閉じたとき、macOSはアプリを終了せずメニューバーを残し、Windows・Linuxはアプリを終了する。文書を閉じたウィンドウは、閉じる・隠すまでの間も「文書がありません」などの文言を表示せず空のままにする。「変更を破棄」は未確定編集を含む対象文書の変更を破棄し、「キャンセル」は文書と編集状態を保つ。

ライブ編集を既定とし、計算結果とMarkdownの装飾を表のセルに表示する。ソース編集では、表の全セルにMarkdown原文を表示する。1つの切替操作が現在の文書内の表すべてに適用され、列ごとの上書き、両方表示、左右比較は設けない。表示モードを変えても内容や未保存状態は変わらない。

編集時は、既存のセル内エディターでフォーカス中のセルのMarkdown原文を編集する。入力を確定すると同じ共通セル編集へ即時反映し、ライブ編集では計算結果とMarkdownの装飾表示へ戻る。ソース編集ではすべてのセルの原文を表示し、そのまま編集する。Markdown文書全体のソース編集・適用・破棄は設けない。

数式バーは待機中と編集中で同じ文字サイズ・余白・縦位置を保ち、外枠は付けない。名前欄と入力欄の間に、Excelと同じく✗（入力の取消）・✓（入力の確定）・`fx`（関数の挿入）のボタンを縦中心を揃えて並べる。✗と✓は編集中だけ押せる。✓は選択を動かさずに確定し、以後の矢印キーはセルを移動する。`fx`は計算できる関数だけの一覧を開き、名前の一部で絞り込める。関数を選ぶとセルに`=関数()`（数式の編集中はキャレット位置に`関数()`）を入れ、キャレットを括弧の間に置いて参照選択の状態にする。続けて文字を入力するか、セルをクリック・ドラッグして範囲を指定できる。数式バーのクリック位置から編集を始め、先頭へ勝手にカーソルを移さない。編集中の入力欄を右クリックすると、元に戻す・やり直す・切り取り・コピー・貼り付け・すべて選択のメニューを開く。右クリックは文字の選択を変えない。

## 5. グリッド操作

### 5.1 入力と移動

選択状態と文字編集中を明確に分離する。以下のCtrlはmacOSではCmdを基本とし、OSの文字編集操作を優先する。

| 操作 | 動作 |
| --- | --- |
| クリック／矢印 | セル選択・移動 |
| F2／ダブルクリック | 現在の原文を編集 |
| 選択中の文字入力／IME開始 | セル内容を置き換えて入力開始 |
| Enter／Shift＋Enter | 確定して下／上へ移動。範囲選択中は範囲を維持して内部を順／逆に巡回 |
| Tab／Shift＋Tab | 確定して右／左へ移動 |
| Esc | 編集開始時の内容に戻る |
| Delete／Backspace | 内容を消去。行列と書式は保持 |
| PageUp／PageDown | 画面1つ分、上／下へ移動。Shift併用で範囲を拡張 |
| Alt＋PageUp／PageDown（Windows） | 画面1つ分、左／右へ移動 |
| Home／End | 同じ行の先頭／末尾へ移動 |
| Shift＋矢印 | 範囲選択 |
| Ctrl/Cmd＋矢印 | 連続データ領域の端へ移動 |
| Ctrl/Cmd＋Shift＋矢印 | 領域の端まで選択 |
| Ctrl＋Home／End | 表の先頭／使用範囲の末尾へ移動 |
| Ctrl＋D／R | 上／左のセルからコピー |

| Ctrl/Cmd＋B／I | 太字／斜体を付ける・外す |
| Ctrl/Cmd＋Shift＋X | 打ち消し線を付ける・外す |
| Ctrl/Cmd＋E | インラインコードを付ける・外す |

選択セルから直接入力を始めた場合、矢印キーは入力を確定して隣へ移動する。F2またはダブルクリックで文字編集へ切り替えると、矢印キーは文字カーソルを動かす。数式の入力中に`=`を入力すると参照選択へ入り、F2で文字編集と参照選択を切り替える。数式バーをクリックして編集を始めた場合も文字カーソルをクリック位置に置く。Tabで続けて入力した後のEnterは、最初に入力した列の次の行へ移動する。通常の矢印移動または別セルのクリックでこの続き入力を終える。

IME変換中のEnter、Esc、矢印はIMEに渡す。変換確定とセル確定を同時に行わない。選択セルからF2を押さずに変換を始めた場合も、そのセルを編集欄にして最初の変換文字から受け取る。Esc、IME無効化、編集欄またはウィンドウのフォーカス喪失、キャレットやフォーカスを移すクリックでは変換前の文字列と選択へ戻す。変換前に確定した通常文字は残し、未確定の変換文字は確定しない。見出しや表タブをクリックした場合、別のウィンドウへ切り替えた場合も、同じ編集バッファを確定してから選択を切り替える。IMEの状態は所有する編集欄だけに適用し、クリックなど他の操作を止めたままにしない。変換中にOSから矢印・Home/End・PageUp/PageDown・BackspaceやDeleteのキーが渡されても、未確定文字の位置を動かさないよう無視する。名前ボックスには `C12` や `A1:D20` を入力して移動・選択できる。番地は相対の `A1` のほか、絶対・混合の `$A$1`・`$A1`・`A$1` でも指定でき、`$` は列記号と行番号の直前に1つずつだけ置ける。行全体・列全体の `$3:$5`・`$C:$E` も同じ。

起動・ファイル読込・文書切替・ダイアログ終了後は、明示的に別の入力欄を操作中でなければ選択セルへキー入力を届ける。表削除にはBackspaceを含む紛らわしいショートカットを割り当てない。メニューの右端へOSに合うショートカット表記を示す。

セルのドラッグとShift＋クリックで矩形範囲を選択し、Ctrl/Cmd＋クリックで追加選択する。ドラッグ中に表示端へ近づくと自動スクロールする。数式編集中にセルをクリック・ドラッグ・矢印操作すると、式を確定せず参照先を式へ挿入し、参照範囲を色付き枠で示す。F2で数式中の文字カーソル移動と参照先の選択を切り替え、IME中は参照選択へ移行しない。

列見出しの境界はサイズ変更のカーソルを示し、ドラッグで列幅を変える。ダブルクリックでは列の内容に合わせて調整する。列全体を複数選んでいるときにその中の列の境界を操作すると、Excelと同じく選んでいるすべての列に同じ幅を適用し、ダブルクリックではすべての列を内容に合わせる（シート全体の選択では表の使用範囲の列まで）。「表示」→「列の幅の自動調整」は表の全列を一括で内容に合わせる。「表示」→「列の幅…」は小数2桁までの数値で幅を指定する。幅の単位はシートの等幅フォントの半角1文字で、幅Nの列にはN文字とセルの左右の余白が入る。幅を指定していない列は既定の幅のまま描く。列幅は省略された内容を読むための表示設定であり、文書内容を未保存にしない。行高は手動で変えず、折り返しやセル内改行に合わせて自動で決まる。Markdownは列幅・行高を保存できないため、行高の手動指定は持たない。

### 5.2 範囲・行列

各表はExcelのシートと同じく、画面いっぱいに並ぶセルとして表示し、どのセルにも移動できる。入力・貼り付けなどで文書が読み込み上限に達したら、その編集を確定して警告を表示する。上限を超える編集は確定せず、どの上限に達したかを伝える。内容を減らす編集は引き続き行える。行列数の上限は1,048,576行×16,384列とする。保存する表はA1を左上に固定し、空でない原文を持つ最も下の行・最も右の列までの矩形とする。範囲内の空行・空列は空セルとして書く。開いたファイルに元からあった行・列は、空でも利用者が行・列の削除を実行しない限り書き残し、Texcelで増えた行・列だけを切り詰める。Markdownでは1行目を見出しとし、値のない見出しも空の見出しとして書く。新しく増えた列の区切り行は既存の列と同じ書き方にそろえる。すべてのセルを空にした新規文書は、Markdownとして有効な最小の表（空の見出し1行と区切り行）を書く。範囲の変化はセル編集と同じ共通編集コマンドに含め、Undoできる。保存範囲を示す追加域の点線や「＋」は表示しない。代わりに、保存範囲に入る行の行番号と列の列記号を濃い文字で示し、範囲外は薄い文字のままとする。入力の確定・貼り付け・消去・Undoで範囲が変わると、その場で表示も変わる。

矩形範囲、行全体、列全体、表全体、複数の離れた範囲を選択できる。行番号と列見出しが交わる左上の角をクリックすると、Ctrl/Cmd＋Aと同じくすべてのセルを選ぶ。行番号・列見出しはExcelと同じく、クリックで1行・1列、ドラッグとShift＋クリックで連続する複数行・複数列、Ctrl/Cmd＋クリックで離れた行・列を追加して選ぶ。選択中の行・列の見出しを右クリックしても選択は変えず、その範囲を右クリックメニューの対象にする。消去・太字・斜体・打ち消し・列の配置は離れた範囲を含む選択全体に一度に適用する。行列の挿入・削除・複製・移動は1つの連続した範囲だけを対象にする。行列の挿入・削除・複製・移動、サイズ調整、固定表示に対応する。固定は「選択セルまで」（選択行までと選択列までの組み合わせ）、「選択行まで」「選択列まで」から選ぶ。固定した行・列の境界はExcelと同じく黒い線で示す（ダークテーマでは明るい線）。行・列の非表示はMarkdownで表せないため編集機能に含めず、XLSX・ODS取込で非表示の行・列があれば省略として報告する。既存の不揃いな行で列フィールドが欠けている位置への入力は、その行だけを必要な幅まで延ばす。

フィルハンドルをドラッグしている間は、その位置で離したときに埋める範囲を選択枠で示し、縦か横の一方へ延ばす位置にないときは元の選択範囲の枠のままとする。離すと、Excelと同じく選択範囲の値の並びで同一値か連続値かを決める。1行または1列に2つ以上並んだ値が等間隔の数値・日付・末尾連番なら続きを作り、それ以外（1セルだけ、数式、並びが読めない値）はコピーする。メニューの連続データの生成は明示的な操作とし、数値・日付・末尾連番を対象とする。先頭ゼロを保持する。対象を一意に解釈できないときは生成せず理由を表示する。

色、罫線、セル結合、数値表示形式、入力規則、条件付き書式は編集・取込の対象にしない。列幅、固定表示などの画面配置はファイルへ保存しない表示設定として扱う。

### 5.3 クリップボード

セル選択中は表データ、文字編集中は文字列として貼り付ける。ExcelやGoogle Sheetsとのタブ・改行・引用符付きデータの受け渡しに対応する。色・罫線・結合・数値表示形式など、Markdownで保存できない書式はコピーでも貼り付けでも扱わない。

通常のコピーと貼り付けは常に同じ規則で動作する。Markdownテーブル等の形式指定や転置・値のみ・空白スキップは、専用の1回限りの操作として選ぶ。名前を付けて保存・形式を選択してコピー・形式を選択して貼り付けのダイアログは、設定画面と同じく左に項目名、右に操作部品を置く行で構成し、項目名を「形式」（ファイルやクリップボードの形式）、「内容」（数式・書式・値の扱い）、「配置」（転置・空白セルのスキップ）にそろえる。「内容」では、数式を残すか計算結果の値にするか、Markdownの書式記号を残すかを同じ言葉で示す。アプリ内では原文・型・Markdown修飾を保持する。

形式を選択して貼り付けは、形式で「自動」（Texcelのデータ、HTML、テキストの順に使う）か「テキストのみ」を、内容で「数式を残す／計算結果の値」と「Markdownの修飾を残す／外す」を、それぞれ独立に選ぶ。Excelの「値」「数式」「値と書式」はこの組み合わせで表す。テキストとして貼り付け（Ctrl/Cmd＋Shift＋V）は「テキストのみ」で数式を残す貼り付けで、文字を入力したのと同じ規則で原文にする。「テキストのみ」で計算結果の値を選ぶと、すべてを文字列として貼り付け、`=` で始まる文字も数式にしない。外部から取り込んだ文字は型推論で別の値へ変えず、入力と同じく原文として保存する。書式のみ・数式と表示形式の貼り付けは設けない。Markdown修飾は原文の一部で別の文字へ移せず、数値表示形式は持たないためである。

コピーした範囲は点線、切り取った範囲は線の種類を変えた点線で示す。点線はEsc、次のコピー・切り取り、文書の編集で消え、クリップボードの内容は残る。貼り付けた数式はExcelと同じく相対参照を貼り付け先へ移動し、絶対参照を保つ。切り取りは貼り付けたときに移動する操作とし、同じ表への通常の貼り付けだけを移動として扱う。移動では元の範囲を空にし、移動したセルを参照する他のセルの数式も移動先を参照させ、全体を1回のUndoで取り消せる。別の表・別の文書・他のアプリへの貼り付けや、形式を選択した貼り付けはコピーとして扱い、元の範囲を残す。

1セルの貼り付けは有限の矩形選択を埋める。複数セルは開始セルから展開し、有限の複数セル選択とサイズが一致しない場合は変更せず選択の修正を求める。シート全体・行全体・列全体の選択では、選択中のセルから貼り付け内容の大きさだけを貼り付ける。離れた複数範囲への貼り付けは行わない。

貼り付けが表の右端・下端を越えても受け入れ、保存範囲が広がる。フィルター機能は設けない。

### 5.4 Undo／Redo

履歴は文書単位で持ち、文書内の全表で共有する。セル編集、貼り付け、行列操作、書式変更、表の追加・削除、一括変換を対象とする。一括操作は1回で取り消せる。別の表に対するUndo／Redoでは対象の表へ切り替え、変更箇所を表示する。

保存や表の切り替えで履歴を消さない。Undo後に新しい編集を確定した場合はRedo履歴を破棄する。テーマ・表示フォント・選択・スクロールなどの表示操作は内容の履歴に含めない。文書を閉じて再度開いた場合の履歴継続は保証しない。

## 6. 数式

Markdown・CSVのセル内容が `=` で始まる場合、既定で数式として評価する。先頭のアポストロフィ列の後ろが `=` の場合だけ、最初の1文字を文字列escape markerとしてファイルへ保存する。`'=A1` は文字列 `=A1` を表し、実際の文字列が `'=A1` で始まる場合は `''=A1` と記録する。`'hello` のように後ろが `=` でない場合はアポストロフィをそのまま表示する。markerを外した残りの文字は再解釈しないため、数式 `="!"` の `!` はシート参照を示さない。 Markdownでは太字やリンクの表示先頭にも同じ規則を使い、例えば `**''=A1**` は太字の文字列 `'=A1` を表す。コード内の記号や、バックスラッシュ・文字参照でエスケープされた実文字をmarkerとして消さない。

数値の扱いはExcelに合わせる。Markdown・CSVのセルは文字列として保存されるため、計算では次の規則で数値とみなす。正規の10進表記（先頭の `-` は任意、整数部は先頭ゼロなし（`0` 単独は可）、小数部と指数部は任意）で、有効数字15桁以内の文字列だけを数値として扱う。`00123`、`+5`、20桁の識別子、桁区切りや日付の文字列は文字列のまま扱う。SUM・AVERAGE・MIN・MAX・COUNTなどの集計関数は、範囲内の文字列を無視する。このため `=SUM(A1:A2)` は文字列 `00123` を合計しない。四則演算（`=A1+1` など）では、Excelと同じく数値に変換できる文字列を変換する。数値として集計したい文字列は `=VALUE()` などで明示する。列配置を指定していないセルは、上の規則で数値とみなす文字列、型付きNumber、Freshな数値の式結果を右寄せにし、それ以外を左寄せにする。`00123` のように数値とみなさない文字列は左寄せのままとする。明示したMarkdownの列配置を優先する。列幅から内容がはみ出す場合や、自動行高の上限を超える場合は省略記号で知らせ、入力値・保存値は短くしない。

XLSX・ODSの同一シート内の数式は数式として取り込む。ODSの式（OpenFormula）はA1形式へ書き換えて取り込み、書き換えられない式は保存された計算結果か空にして変換レポートにセルを示す。別シート・外部ブック参照を含む式は式として取り込まず、ファイル内に保存された計算結果があれば値として、なければ空として取り込み、変換レポートにセルを示す。HTML・XLSX・ODSから取り込んだ元ファイルは変更しない。

四則演算、比較、文字列結合、セル・範囲参照、絶対／相対参照、基本的な集計・条件・文字列・日付関数を扱う。具体的な対応範囲は詳細設計書に定める。テキスト形式の表をまたぐ参照、外部ブック参照、マクロは実行しない。

変更に応じて再計算する。未対応、循環参照、計算中、計算エラー、ファイルに保存された結果を区別する。再計算できない結果を最新の結果として表示しない。

通常は式を保持し、ライブ編集ではFreshの計算結果を表示する。「結果で置き換える」は明示的な編集操作とし、Undoできる。数式を含むMarkdownを他のビューアで開くと式の文字列が表示される。

## 7. Markdown

GFMのパイプテーブルを対象とする。コードブロック内の見かけ上のテーブルは対象にしない。表一覧には表名と、A1から直線距離で最も近い値の入ったセルの内容を表示する。値が1つもない表だけを「空の表」と表示する。表の追加・複製・削除、列の左／中央／右寄せに対応する。表を削除するときは、その表の名前の元になった直前の見出しも、表との間に他の文章がない場合に限って一緒に削除する。

セル内は太字、斜体、打ち消し、インラインコード、リンク、改行を描画する。区切り行で指定した配置は、ライブ編集とソース編集の両方で見出しと本文に適用する。列見出しには区切り行と同じ位置に`:`を小さく表示し、左寄せは左端、中央寄せは両端、右寄せは右端に付け、配置を指定していない列には付けない。「列を右寄せ」などの書式操作は選択したセルを含む列全体に効く。空の列に配置を指定しても保存範囲は広がらない。範囲外の配置は文書を開いている間だけ保持することを設定時に一度知らせ、その列に値を入力して保存すると配置も記録する。画像は代替テキストと画像であることを表示し、自動取得しない。任意HTMLは実行せず、改行用の `<br>` だけを表示上の改行として扱う。

書式メニューとショートカットによる修飾操作は、原文の記法を追加・解除する。編集中の未完成な記法はそのまま編集できる。通常クリックはセル選択とし、リンクはCtrl＋クリックまたは専用操作で開く。CSVから取り込んだ文字列は、Markdown構文に見えても自動で修飾として解釈しない。Markdown編集文書へ移行するときは、元の文字列表示を保つよう記法をエスケープする。明示的な修飾操作で初めてMarkdown記法を付ける。

セル編集では列区切りを含まないMarkdown原文を扱う。Markdown文書のセル内改行は原文の `<br>` で表し、Alt＋Enterは編集中の位置へ `<br>` を入力する。CSV文書のAlt＋Enterは改行文字を入力し、1行の編集欄では改行文字を `↲` で示す。貼り付けなどで原文に入った改行文字は保存時に `<br>` へ変換し、パイプは必要なエスケープを行う。不可視文字の表示を有効にすると、ライブ編集では改行の位置に `↲` を示す。CSV・TSVへ保存するときは `<br>` を改行文字に置き換える。ライブ編集とソース編集で同じセル内容を扱う。

保存時は周辺文章を保持し、表全体を整形し直さない。Texcelが書いたセルは、値の前後に空白を1つずつ置く（詰めて書かれた行では空白なし）。列数が不揃いな表は余剰セルを隠さず表示し、セルの個数をそのまま保つ。

## 8. CSV・TSV

保存値は原則文字列とする。先頭ゼロ、長い数値、日付らしい文字列を自動変換しない。計算での扱いは6節に従う。数値の正規表記の文字列は数値として計算し、`00123` のような文字列は集計関数で無視する。表示の既定はTextが左、型付きNumberとFreshな数値の式結果が右で、Markdownの明示配置を優先する。内容がセルの表示範囲を超えるときは省略記号を付け、保存値を保持する。

カンマ、タブ、セミコロン、指定した1文字の区切り、UTF-8・BOM付きUTF-8・CP932、LF・CRLFに対応する。引用符内の区切り、改行、二重引用符を正しく扱う。

不揃いな行のフィールド数、空フィールド、末尾改行、空行を保持する。文字コードや引用符が不正な場合、黙って文字を置き換えたり修復したりしない。

## 9. XLSX・ODSの変換範囲

XLSXとODS（OpenDocument表計算）は取り込み専用とする。各シートをMarkdownの表として編集し、XLSX・ODSへの保存・出力は行わない。ExcelやLibreOfficeの完全互換読込や、未知の要素の保持は保証しない。

| 情報 | 対応 |
| --- | --- |
| シートとセルの値 | Markdownの表へ取り込み |
| 同一シートの式 | 対応範囲内で数式として取り込み |
| 別シート・外部ブック参照の式 | 保存済み計算結果、または空へ変換して報告 |
| 色、罫線、数値表示形式、入力規則、条件付き書式 | 扱わず、読み込みレポートで損失を示す |
| 結合セル | 左上の値を残し、ほかの座標を空にして取り込む |
| シートのその他の表示設定や非対応要素 | 読込内容に応じてレポートする |
| ODSで書式だけを持つ空のセル | 表の範囲に含めない（LibreOfficeがシート端まで繰り返し書くため） |
| 暗号化ファイル、XLS・XLSB・XLSM、1ファイルXML版のFODS、旧形式のSXC | 入力対象外 |

読み込み中は項目ごとの確認を求めず、読み込み完了後に変換レポートをまとめる。値・数式・表構造が失われる場合はモーダルダイアログを1回自動表示する。色・罫線など表示上の書式だけが失われる場合は、状態欄に注意の通知と「詳細」を表示し、「詳細」からレポートを開ける。この通知は利用者が閉じるか文書を閉じるまで残す。ファイルメニューにはレポートの項目を置かない。レポートには拡張子を含む入力ファイル名、利用者のOS地域とローカル時刻で表示した読み込み日時、対象のシート・範囲と理由を示す。ダイアログの題名は取り込んだ形式名を付けて「XLSX読み込みレポート」「ODS読み込みレポート」「HTML読み込みレポート」とする。本体は「結果」（保持・変換・欠落などの分類）、「箇所」（シート・表と件数）、「詳細」（選んだ行の場所・理由・対象範囲）の3列とし、各列の上に見出しを付ける。行は結果と箇所の2列にまたがって選び、項目を選び替えても高さを変えない。「閉じる」「ファイルに保存」を用意し、保存は任意とする。通知は取り込んだ文書のウィンドウに表示し、別の文書と混同させない。HTMLにも同じレポート規則を適用し、読み取り専用表示やHTMLセルの書き戻しは行わない。

レポートは読み込み結果の説明であり、元ファイルを書き換えたり、取り込み結果の承認を必須にしたりしない。読み込み自体が失敗した場合はエラーを表示する。ファイル全体を確認していない段階で「情報損失なし」とは表示しない。名前を付けて保存でCSVを選んだ場合は別途、現在の内容と出力形式による変換・欠落を書き出し前にまとめて確認する。

Markdown保存は現在の文書全体を対象とする。CSV保存は、利用者が明示的に選択した1つの表だけを対象にする（3節）。複数表やMarkdown修飾など保存されない内容を事前に示す。文書全体を表現できないCSV保存では、元のMarkdown文書、未保存の編集、path、Undo履歴を維持する。CSV保存を文書全体の保存として扱い保存先を切り替えるのは、全内容を表現できる場合に限る。XLSX・ODS・HTMLの保存形式はない。

変換によって編集中のセル内容を変更しない。文書全体を表現できないCSV保存の成功は、元文書の未保存状態を解除しない。文書全体を表現できる保存では、前述の規則に従って保存先と保存済み版を更新する。

入力形式と保存先の組み合わせごとに、引き継ぐ情報と失う情報は次のとおりとする。元の形式へ戻せば失った情報が戻る、という往復互換は保証しない。

| 入力 → 保存先 | 引き継ぐ情報 | 失う情報・注意 |
| --- | --- | --- |
| Markdown → Markdown | セルの原文、数式、修飾、列配置、表外の文章、未編集部分のバイト列 | 構造を変更した表は、その表の記法を書き直す |
| Markdown → CSV | 選んだ1表の文字列と、選んだ式または計算結果 | 他の表、表外の文章、修飾、リンク先、列配置 |
| CSV・TSV → Markdown | 文字列と数式。既存の記号を修飾として解釈しない | 引用符・区切り文字・文字コード・改行方式 |
| CSV・TSV → CSV・TSV | 選んだ形式が元の区切り文字を保てる場合（TSVはタブ、CSVはタブ以外）は、元の区切り文字・文字コード・改行・未編集部分 | 追加した表やMarkdown修飾は保存しない。区切り文字を変える場合はUTF-8・LFで書き直す |
| XLSX・ODS・HTML → Markdown | 値、同一シート内の式、対応する修飾・リンク・セル内改行、列で一致する水平配置 | 色、フォント指定、罫線、数値表示形式、結合、入力規則、条件付き書式、CSS、表外の文章 |
| XLSX・ODS・HTML → CSV | 取り込み後の1表の式または値 | 上記に加え、他の表、修飾、リンク先、列配置 |

## 10. データ整理と表示支援

検索・置換は選択範囲、表、文書を対象にし、原文／表示結果を選べる。表示結果に対する直接置換は行わず、原文の変更内容を確認して適用する。完全一致、部分一致、大小文字、正規表現に対応する。

複数列による安定ソート、重複検出・削除、前後空白除去、列分割・結合、転置に対応する。一括変更は1回のUndoで取り消せる。

並べ替えは行順を変更する編集操作とし、表全体の行を移動する。先頭行を見出しとして並べ替えから除くかは、並べ替えの画面で選ぶ（Markdownは見出し行を常に除く。CSVは既定で除かない）。表示倍率、折り返しなどの閲覧設定だけではデータを変更しない。

状態欄に表示するのは、利用者の指示による処理の完了通知、利用者が対処すべき失敗と注意（指示の入力が正しくない、指示を実行できない、処理を完遂できないなど）、処理中の取消ボタン、2つ以上のセルを選んだときの右端の個数と、選択が及ぶ行数・列数（例：「6 個のセルを選択（3 行 × 2 列）」。離れた範囲は重なりを1回と数える）だけとする。完了通知は、保存・書き出し・レポートの保存・置換・データの整理・行列の挿入／削除／複製／移動・フィル・大きな貼り付け・表の追加／複製／削除／名前の変更・列の配置の変更のように、処理を受け付けてから終わるまで時間のかかりうる指示が成功したときに出す（例：「2行を挿入しました」「『売上.md』を保存しました」）。セルへの入力やコピーなど、結果がその場で見える操作では出さない。行列構造の準備・検索・貼り付けの準備・再計算・書き出しなど、内部の処理状態は文で表示しない。個数は範囲をドラッグしている最中も更新し、フィルハンドルのドラッグ中は離したときに埋める範囲の個数を示す。文書名は表示しない。合計・平均などの統計は表示しない。通知の文は、何が起きて利用者が何をすればよいかを示し、内部の用語を使わない。注意の通知は一定時間が経つか次の操作で消し、古い通知を残さない（取り込みの注意は9節の規則による）。未保存状態はウィンドウタイトルの印で示す。

日本語フォント、DPI変更、ダーク／ライト表示、不可視文字表示、キーボード操作、スクリーンリーダー向けセル情報に対応する。アクセシビリティはOSと採用バックエンドの対応差を明示し、全OSで同等と断言しない。

表示フォントは文書ではなくアプリ全体の設定とし、「自動」「デフォルト」「Noto Sans（日本語対応）」から選ぶ。既定は自動で、アプリの表示言語が日本語ならNoto Sans、英語ならデフォルトを使う。利用者がデフォルトまたはNoto Sansを明示的に選んだ場合は、言語を変えても切り替えない。Noto Sans設定では日本語と英数字をともにNoto Sans CJK JPで描画し、異なるフォントの混在による位置のずれを減らす。原文・コード用の等幅表示には対応するNoto Sans Mono CJK JPを使用する。

設定画面に日英混在のプレビューを表示し、選択は再起動なしで閲覧セル・編集セル・編集バー・アプリUIへ反映する。表示フォントの変更はファイル内容を変更しない。OSに任意フォントのインストールを求めず、プリセットを同梱する。「自動」以外の自動切り替えや、ベースラインの手動補正設定は設けない。

外観もアプリ全体の設定とし、「システムに従う（既定）」「ライト」「ダーク」から選ぶ。システムに従う場合はOSから通知される外観変更に追従し、OS設定を取得できない場合はライトを使用する。設定変更は再起動なしで反映する。

背景・文字・グリッド線・選択範囲・編集セル・エラー表示をテーマに合わせる。テーマ変更によってファイル内容やMarkdown修飾、未保存状態を変更しない。

## 11. 保存・復旧・応答性

未編集のCSV・Markdownを通常保存してもバイト列を変更しない。変更時も不要な全体整形をしない。保存中の失敗で元ファイルを壊さず、編集状態を保持する。

開いたファイルの内容はメモリに読み込み、編集と保存に元のファイルを必要としない。編集中にディスク上のファイルを監視せず、変更や削除を知らせない。保存するときだけ、ディスク上のファイルが開いた時点（または最後に保存した時点）から他のアプリで変更されていないかを確かめる。変更されていた場合は「上書き」「名前を付けて保存…」「キャンセル」を1回だけ確認する。自動マージや差分表示はしない。ファイルが無くなっていた場合は、確認せずに同じ場所へ作り直す（元のフォルダーがなければ名前を付けて保存へ案内する）。

異常終了に備えて編集状態を退避するが、元ファイルへ自動保存しない。次の起動時は、退避した未保存の作業を確認なしにそれぞれ未保存の文書ウィンドウとして開く。元ファイルが変わっていても上書きせず、保存時の確認（前段落）に従う。不要な作業は、そのウィンドウを閉じるときに「変更を破棄」を選べば破棄できる。復元の一覧ダイアログやファイルメニューの復元項目は設けない。

列幅や表示モードなどの画面設定はアプリのローカル設定に保存する。数式評価はMarkdown・CSVで常時有効とし、表ごとの有効化設定を設けない。画面設定はファイル単体では他端末へ移らない。設定を失っても原文を失わない。

読み込み、計算、一括変換、保存は画面処理から分離する。可視範囲だけを描画し、処理中も移動・スクロールを維持する。長い処理には進捗とキャンセルを提供し、変更は全体が成功した時点で反映する。

詳細な状態遷移、データ構造、保存規則、技術選定根拠は [詳細設計書](detail-spec.md) を参照する。
